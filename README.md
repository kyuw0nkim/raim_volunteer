# RAIM 업무 대시보드

RAIM 업무를 보드별로 관리하는 페이지 모음입니다 (GitHub Pages).

| 주소 | 보드 | 내용 |
|---|---|---|
| `/` | RAIM 업무 대시보드 | 두 보드에서 오늘 챙길 일만 모아 보여줌 |
| `/volunteer/` | 자원봉사 보드 | 1365 명단 확인, 배치, 출석, 1365 실적 입력, 활동기록부 엑셀 |
| `/atelier/` | 아뜰리에 관리 보드 | 할 일·제안 업무, 개관·마감 점검, 재고, 장비 이슈, 달력 |

- 데이터: 구글 스프레드시트 하나 (`apps-script/` 폴더의 Apps Script 웹앱)
- 세 페이지가 같은 웹앱 주소·접속 코드를 씁니다. 한 브라우저에서 한 번만 넣으면 됩니다.

### 여러 사람에게 연결하기 — 연결 링크

한 번 연결된 기기에서 **연결 링크 복사**(대시보드 위쪽, 자원봉사 보드 `설정` 아래, 아뜰리에 보드 `설정 → 이 기기`)를 누르고 단톡방 등에 올리면, 다른 사람은 그 링크를 한 번 여는 것만으로 연결됩니다 (세 보드 모두). 링크의 주소·코드는 브라우저에 저장된 뒤 주소창에서 바로 지워지고, `#` 뒤 부분이라 GitHub Pages 서버로도 전송되지 않습니다. 다만 링크 자체에 접속 코드가 들어 있으니 필요한 사람에게만 공유하세요.

### 보드별 권한 — 보드 전용 접속 코드

접속 코드는 세 가지입니다. 웹앱이 요청마다 코드를 확인하므로, 전용 코드로는 다른 보드의 데이터를 받아 갈 수 없습니다.

| 코드 | 열 수 있는 보드 | 만드는 법 (Apps Script 편집기에서 실행 → 실행 로그에 코드) |
|---|---|---|
| 전체 코드 | 두 보드 모두 | `보드_설치` (처음 한 번), 바꿀 때 `보드_접속코드바꾸기` |
| 자원봉사 전용 | 자원봉사 보드만 | `보드_접속코드_자원봉사만` |
| 아뜰리에 전용 | 아뜰리에 보드만 | `보드_접속코드_아뜰리에만` |

- 다시 실행하면 새 코드가 만들어지고 예전 코드는 막힙니다. 전용 코드를 모두 없애려면 `보드_보드별코드_모두없애기`.
- `보드CONFIG.보드주소`를 넣어 두면 실행 로그에 그 보드로 바로 가는 연결 링크도 나옵니다. 아니면 전용 코드로 연결한 기기에서 `연결 링크 복사`를 누르면 됩니다.
- 전용 코드로 연결하면 대시보드에는 그 보드만 보이고, 다른 보드를 열면 "이 접속 코드로는 열 수 없어요"가 뜹니다.
- 자원봉사 보드에는 봉사자 이름·연락처가 있으니, 아뜰리에만 쓰는 사람에게는 아뜰리에 전용 코드를 주세요.

**웹앱 주소는 되도록 바꾸지 마세요.** Apps Script를 고친 뒤 `새 배포`를 만들면 주소가 바뀌지만, `배포 관리 → 편집(연필) → 버전: 새 버전 → 배포`로 하면 주소가 그대로입니다. 주소가 바뀌었을 때만 새 연결 링크를 다시 올리면 됩니다.

이 저장소에는 봉사자 개인정보가 들어가지 않습니다. 명단과 연락처는 스프레드시트에만 저장되고, 페이지는 웹앱 주소와 접속 코드로 연결합니다. 둘 다 저장소에 올리지 마세요.

## Apps Script 설치 · 업데이트

1. 스프레드시트의 Apps Script 편집기에서 `보드.gs`를 이 저장소의 `apps-script/보드.gs` 내용으로 바꾸고, `아뜰리에.gs` 파일을 새로 만들어 `apps-script/아뜰리에.gs` 내용을 붙여넣습니다.
   (예전 `보드_기존데이터가져오기`는 9월 데이터를 옮길 때 한 번 쓴 함수라 뺐습니다.)
2. `보드_설치`를 한 번 실행합니다. 아뜰리에 탭이 생기고 알림이 다시 예약됩니다. 접속 코드는 그대로입니다. (보드별 코드가 필요하면 아래 '보드별 권한' 참고)
3. **배포 → 배포 관리 → 편집 → 버전: 새 버전 → 배포.** 웹앱 주소는 그대로 유지됩니다.

## 여는 속도

Apps Script 웹앱은 요청마다 1~4초가 걸려서, 세 페이지 모두 이렇게 동작합니다.

- 마지막으로 본 내용을 브라우저에 저장해 두었다가 열자마자 보여주고, 시트는 뒤에서 확인합니다 (`최신 내용 확인 중…` → `시트에 저장됨`). 다른 기기에서 바뀐 게 있으면 그때 새로 그립니다.
- 뒤에서 확인할 때는 가진 판(version)만 보내고, 바뀐 게 없으면 웹앱이 내용 없이 `same`만 돌려줍니다.
- 웹앱은 판별로 불러온 내용을 캐시해 두고 시트를 다시 읽지 않습니다. 저장하면 판이 올라가서 다음에 한 번 새로 읽습니다. 라메 명단은 10분 캐시입니다.
- 저장되기 전에 창을 닫으면, 다음에 열 때 이어서 저장합니다.
- 두 기기에서 동시에 고쳐도 서로 덮어쓰지 않습니다. 늦게 저장한 쪽이 시트의 최신 내용을 받아, 자기가 바꾼 부분만 그 위에 얹어 다시 저장합니다 (`다른 기기 변경과 합치는 중…`). 자원봉사 보드는 날짜 칸·1365 공고별 확인·봉사자 한 명의 칸(출석, 1365 입력, 메모, 배치 등) 단위로 합치고, 같은 칸을 둘 다 고쳤으면 늦게 저장한 쪽이 남습니다. 같은 명단을 두 기기에서 붙여넣어도 한 번만 들어갑니다.
- 브라우저에 저장되는 내용에는 봉사자 이름·연락처가 들어갑니다. 공용 PC에서는 쓰지 마세요.

**시트를 직접 고쳤다면** (`보드_`·`아뜰리에_`·`라임메이트` 탭) Apps Script 편집기에서 `보드_캐시비우기`를 한 번 실행하세요. 판이 올라가서 열려 있는 보드들이 시트를 다시 읽습니다.

## 자원봉사 보드

### 스프레드시트 탭

| 탭 | 내용 |
|---|---|
| `보드_기록` | 봉사자 한 명이 한 줄 (날짜, 시간대, 배치, 출석, 1365 입력, 메모) |
| `보드_날짜` | 날짜별 명단 확인, 휴관, 로공방 운영, 공지 추가 문구, 1365 공고별 확인(`확인항목`) |
| `보드_활동기록입력` | 활동기록부 변환(① 이름순, ② 첫 활동일순)이 읽는 입력 탭. 결석은 `미승인 = 1` |

라메 명단은 기존 `라임메이트` 탭의 이름 열을 읽습니다.

### 활동기록부 엑셀

`설정` 화면의 **활동기록부 다운로드**에서 달을 고르면 기관 제출 양식(성명·연락처·구분·날짜별 오전/오후/전일)으로 `.xlsx`를 내려받습니다.

- 출석(`출석`)으로 표시한 기록만 들어갑니다.
- 이름과 연락처가 모두 같아야 같은 사람으로 합칩니다.
- 첫 활동일순, 같은 날은 이름순으로 정렬합니다. 라메는 `구분`에 `라임메이트`로 적힙니다.
- 파일은 브라우저 안에서 만들어지고 다른 곳으로 전송되지 않습니다 (엑셀 도구 ExcelJS만 cdnjs에서 불러옵니다).

## 아뜰리에 관리 보드

여러 사람이 각자 휴대폰·PC로 씁니다. 처음 무언가를 기록할 때 이름을 한 번 물어보고 그 기기에 기억합니다. 두 사람이 동시에 저장해도 서로의 기록을 덮어쓰지 않도록, 늦게 저장한 쪽이 최신 내용을 받아 자기 변경을 다시 얹어 저장합니다.

| 탭 | 내용 |
|---|---|
| 오늘 | 할 일(때가 된 주기 업무 + ‘필요해요’ 표시된 업무), 제안 업무, 개관·마감 점검 체크리스트, 재고 부족, 해결 안 된 장비 이슈 |
| 달력 | 한 일(초록), 예정(점선), 장비 이슈. 날짜를 누르면 그날 기록·점검 보기, 지난 날 기록 추가 |
| 재고 | 수량 −/+ 조정, 부족 기준, `재고 조사 완료`(오늘 날짜로 기록), 부족 목록 복사, 조사 기록 |
| 장비 이슈 | 등록 → 해결 처리(처리 내용 메모), 다시 열기 |
| 설정 | 업무 추가·수정, 점검 항목, 기록자 이름, 연결 설정 |

업무 종류

- **주기**: 꼭 정해진 간격으로 하는 일. 마지막으로 한 날부터 N일 뒤가 다음 예정일입니다 (휴관일이면 다음 운영일). 때가 되면 `할 일`에 올라오고, 아직이면 `다가오는 루틴`에 접혀 있습니다. 예: 그린바이 물갈이 7일
- **필요시 (제안)**: "언제쯤 하면 좋겠다" 정도의 일. 예정일 없이 `제안 업무` 칸에 있고, 누구든 `필요해요`를 누르면 `할 일`로 올라갑니다. 완료하면 표시가 풀려 다시 제안 업무로 내려갑니다. 예: 헬프로봇 번호 정리, 머신러닝 카드 재분류·만들기, 재고 조사
  - `제안(일)`을 넣으면 그만큼 안 했을 때 `제안`으로 표시되어 제안 업무 맨 위에 뜹니다 (아침 메일에도 들어감).
  - `나중에`를 누르면 7일 동안 제안에서 빠집니다. `이미 했어요`로 바로 완료할 수도 있습니다.
  - 설정에서 종류를 바꾸면 간격이 그대로 옮겨갑니다 (주기 30일 → 제안 30일).

휴관일은 자원봉사 보드와 같습니다 (월요일, 그리고 자원봉사 보드에서 날짜별로 바꾼 휴관).

### 스프레드시트 탭

| 탭 | 내용 |
|---|---|
| `아뜰리에_업무` | 업무 목록 (종류, 주기, 제안 간격(`알림(일)` 열), 방법, 필요 표시, 제안 미룸) |
| `아뜰리에_업무기록` | 업무를 한 날·한 사람·메모 |
| `아뜰리에_재고` | 품목별 현재 수량·부족 기준·위치 |
| `아뜰리에_재고기록` | 재고 조사할 때마다 품목별 수량 |
| `아뜰리에_장비이슈` | 등록·해결 기록 |
| `아뜰리에_점검항목` | 개관·마감 점검 항목 |
| `아뜰리에_점검기록` | 날짜별로 체크한 항목·사람·시각 |
