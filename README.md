# RAIM 자원봉사 보드

1365 명단 확인, 봉사자 배치, 출석, 1365 실적 입력을 날짜별로 관리하는 페이지입니다.

- 화면: 이 저장소의 `index.html` (GitHub Pages)
- 데이터: 구글 스프레드시트 (`보드.gs` Apps Script 웹앱)

이 저장소에는 봉사자 개인정보가 들어가지 않습니다. 명단과 연락처는 스프레드시트에만 저장되고, 페이지는 웹앱 주소와 접속 코드로 연결합니다. 둘 다 저장소에 올리지 마세요. 처음 접속할 때 기기마다 한 번씩 입력하면 됩니다.

## 스프레드시트에 생기는 탭

| 탭 | 내용 |
|---|---|
| `보드_기록` | 봉사자 한 명이 한 줄 (날짜, 시간대, 배치, 출석, 1365 입력, 메모) |
| `보드_날짜` | 날짜별 명단 확인, 휴관, 로공방 운영, 공지 추가 문구 |
| `보드_활동기록입력` | 활동기록부 변환(① 이름순, ② 첫 활동일순)이 읽는 입력 탭. 결석은 `미승인 = 1` |

라메 명단은 기존 `라임메이트` 탭의 이름 열을 읽습니다.

## 활동기록부 엑셀

`설정` 화면의 **활동기록부 다운로드**에서 달을 고르면 기관 제출 양식(성명·연락처·구분·날짜별 오전/오후/전일)으로 `.xlsx`를 내려받습니다.

- 출석(`출석`)으로 표시한 기록만 들어갑니다.
- 이름과 연락처가 모두 같아야 같은 사람으로 합칩니다.
- 첫 활동일순, 같은 날은 이름순으로 정렬합니다. 라메는 `구분`에 `라임메이트`로 적힙니다.
- 파일은 브라우저 안에서 만들어지고 다른 곳으로 전송되지 않습니다 (엑셀 도구 ExcelJS만 cdnjs에서 불러옵니다).
